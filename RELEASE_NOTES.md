# Release notes

## 0.1.0 – first preview (not published)
- Recording with hardware encoding (NVENC/QuickSync/AMF, x264 fallback), MP4/MKV, display or window capture.
- Instant replay 15 s – 5 min with a save hotkey; screenshots; recording overlay.
- Clip library with thumbnails, preview, search/filter/sort, folders, favourites, rename, delete, export, lossless trim.
- Sonar-style mixer: Game/Chat/Media/Aux/Mic/Master, per-app volume and channel assignment, live meters, profiles.
- 9-band parametric EQ with presets and live curve.
- Microphone chain: gain, noise gate, noise suppression, compressor, limiter, monitoring, routing to a virtual cable.
- Soundboard: import common formats, collections, volume, loop, global shortcuts, two outputs.
- Optional Google Drive sync of chosen clips (PKCE, drive.file, resumable).
- Optional HTTPS remote dashboard with pairing code.
- Global shortcuts, accent colours, keyboard navigation, `--self-test` and `--screenshot`.

See PROGRESS.md for what is tested and what is not.
